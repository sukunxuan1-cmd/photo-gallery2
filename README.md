# ✦ 美森耐 · 时光画廊

一个酷炫的照片展示网站：星空粒子背景、流星、极光氛围、3D 倾斜相册卡片、自定义光标、灯箱幻灯片，还有自动播放的梦幻 BGM。

## 🚀 怎么用（两步）

1. **打开网页**：双击 `启动网页.bat`（需要电脑装有 [Python](https://www.python.org/downloads/)，安装时勾选 *Add Python to PATH*），浏览器自动打开。
2. **放照片**：随时把照片丢进 `photos/` 下对应的活动文件夹（新建文件夹也会自动识别），**刷新浏览器即可显示**——网页会实时扫描文件夹，无需任何手动步骤。

> 没装 Python 的备用方案：直接双击 `index.html` 也能看，但照片需要先双击 `更新照片.bat` 生成清单，且 3D 场景里照片受浏览器限制无法显示。

## 🎵 背景音乐

- 默认：网页会用 Web Audio 实时合成一段梦幻氛围音乐，**无需任何音频文件**。
- 想用自己的歌：把 mp3 改名为 `bgm.mp3` 放进 `assets/` 文件夹即可，会自动优先播放。
- 点击右上角的 **BGM** 按钮可随时开关；第一次点击页面任意位置也会自动开始播放（浏览器规定需要先有交互才能出声）。

## ✨ 网页亮点

- **3D 照片星河 🌌**（three.js / WebGL）：照片化作星辰组成三条旋臂的银河，围绕发光的「美森耐」核心旋转；拖动旋转、滚轮飞入穿梭、悬停照片放大、点击欣赏
- **虚拟美术馆 🏛️**（three.js / WebGL）：第一人称漫游的金框画廊，W/S 或 ↑↓ 行走、拖动环顾、点击画作放大，照片配金色名牌，尽头是金字招牌（three.js 已内置在 `libs/`，断网可用）
- **照片汇聚成字**：打开网页时，照片碎片从四面八方飞来，汇聚成「美森耐」三个大字再炸裂散开（右侧 ✨ 按钮可重播）
- **电视墙模式 📺**：一键全屏照片墙，格子不停轮换照片，每隔几秒随机放大一张特写——年会/活动现场投大屏神器
- **照片盲盒 🎁**：礼物盒摇晃、金色粒子炸开，随机弹出一段回忆，「还记得这一天吗？」，可以一直抽
- **烟花庆祝 🎆**：开启后烟花自动升空绽放，点击屏幕任意处还能手动加放一发
- **照片专属弹幕 💬**：在灯箱或 3D 放大层看照片时，给这张照片发弹幕；每张照片的弹幕只在它自己身上循环飘过。配置云端后**全员共享**（见下方「云端共享弹幕」），未配置则保存在各自浏览器本地
- **发布自动压缩大图**：GitHub Actions 发布时自动把超 400KB 的照片压到最长边 1920px（仓库保留原图），13MB 手机原图实测压到 0.3MB
- **3D 时光相框**：金边相框组成的 3D 旋转环，每次打开随机抽照片放入，每 5 秒翻面换一批，可拖动旋转
- 开场加载动画 + 标题逐字浮现
- 星空粒子背景：星星会躲开鼠标，偶尔划过流星
- 极光色彩氛围 + 噪点质感
- 自定义发光光标 + 按钮磁吸效果
- 相册卡片：3D 倾斜、扫光、封面缩放
- 照片瀑布流 + 滚动交错入场
- 灯箱：键盘 ←/→ 切换、手机滑动切换、Esc 关闭
- 一键幻灯片自动播放（带进度条）
- 统计数字滚动动画（照片数 / 相册数 / 天数）
- 手机端完全适配

## 📁 项目结构

```
photo-gallery2/
├── index.html        # 主页面
├── css/style.css     # 全部样式与动效
├── js/main.js        # 交互逻辑（粒子、画廊、灯箱、BGM）
├── js/photos.js      # 照片清单（由脚本自动生成）
├── photos/           # ⭐ 照片放这里，按活动分文件夹
├── assets/           # 可选：放 bgm.mp3
├── tools/build_photos.py  # 扫描照片生成清单
├── 更新照片.bat       # 一键更新照片清单
└── 启动网页.bat       # 一键启动本地网页
```

## ☁️ 云端共享弹幕（可选，免费）

默认弹幕只存在每个人自己的浏览器里。想让**所有访客互相看到彼此的弹幕**，接入 Supabase（免费额度远超够用），一次性设置约 5 分钟：

1. 打开 [supabase.com](https://supabase.com)，用 GitHub 账号登录 → **New project** 建一个免费项目（区域选 Singapore 或 Tokyo 较快）
2. 项目左侧 **SQL Editor** → 把 `tools/supabase_setup.sql` 的内容整段粘贴 → **Run**
3. 左侧 **Settings → API**：复制 **Project URL** 和 **anon public** key
4. 填进 `js/cloud-config.js` 的 `url` 和 `anonKey`，提交（合并进 main 后 Pages 生效）

配置后：发的弹幕实时写入云端，看同一张照片的人每 12 秒自动同步到新弹幕。anon key 设计上就是公开的，配合 SQL 里的行级安全策略，访客只能读弹幕、发弹幕，不能改删。

## ❓ 常见问题

**在 GitHub 网页上传了照片，Pages 网站没显示？**
照片要上传到 **main 分支** 的 `photos/对应文件夹` 里。每次推送 main，GitHub Actions 会自动重新扫描照片并发布 Pages（约 1-2 分钟生效，第一次需在仓库 Settings → Pages → Source 选择 **GitHub Actions**）。

**星河 / 美术馆里看不到照片，只有占位图？**
是因为网页是双击 `index.html` 打开的（地址栏 `file://` 开头）。浏览器安全限制禁止 3D（WebGL）读取本地图片。
👉 解决：用 **`启动网页.bat`** 打开（地址为 `http://localhost:8520`），照片即可正常显示。该脚本启动前还会自动帮你更新照片清单。

**放了新照片网页里没出现？**
用 `启动网页.bat` 打开时只需刷新浏览器（实时扫描）。只有双击 `index.html` 直接打开时，才需要先双击 `更新照片.bat` 生成清单。
