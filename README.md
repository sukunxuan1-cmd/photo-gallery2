# ✦ 遇见幸福 · 时光画廊

一个酷炫的照片展示网站：星空粒子背景、流星、极光氛围、3D 倾斜相册卡片、自定义光标、灯箱幻灯片，还有自动播放的梦幻 BGM。

## 🚀 怎么用（三步）

1. **放照片**：把照片放进 `photos/` 下对应的活动文件夹（也可以自己新建文件夹，会自动识别）。
2. **更新清单**：双击 `更新照片.bat`（需要电脑装有 [Python](https://www.python.org/downloads/)，安装时勾选 *Add Python to PATH*）。
3. **打开网页**：双击 `启动网页.bat`，浏览器会自动打开。

> 没装 Python 也能看：直接双击 `index.html`，但放新照片后需要先运行一次更新脚本才会显示。

## 🎵 背景音乐

- 默认：网页会用 Web Audio 实时合成一段梦幻氛围音乐，**无需任何音频文件**。
- 想用自己的歌：把 mp3 改名为 `bgm.mp3` 放进 `assets/` 文件夹即可，会自动优先播放。
- 点击右上角的 **BGM** 按钮可随时开关；第一次点击页面任意位置也会自动开始播放（浏览器规定需要先有交互才能出声）。

## ✨ 网页亮点

- 开场加载动画 + 标题逐字浮现
- 星空粒子背景：星星会躲开鼠标，偶尔划过流星
- 极光色彩氛围 + 噪点质感
- 自定义发光光标 + 按钮磁吸效果
- 相册卡片：3D 倾斜、扫光、封面缩放
- 照片瀑布流 + 滚动交错入场
- 灯箱：键盘 ←/→ 切换、手机滑动切换、Esc 关闭
- 一键幻灯片自动播放（带进度条）
- 统计数字滚动动画（照片数 / 相册数 / 天数）
- 手机端完全适配

## 📁 项目结构

```
photo-gallery2/
├── index.html        # 主页面
├── css/style.css     # 全部样式与动效
├── js/main.js        # 交互逻辑（粒子、画廊、灯箱、BGM）
├── js/photos.js      # 照片清单（由脚本自动生成）
├── photos/           # ⭐ 照片放这里，按活动分文件夹
├── assets/           # 可选：放 bgm.mp3
├── tools/build_photos.py  # 扫描照片生成清单
├── 更新照片.bat       # 一键更新照片清单
└── 启动网页.bat       # 一键启动本地网页
```

## 支持的图片格式

jpg / jpeg / png / gif / webp / bmp / jfif / avif
